# 夜間育児の記録・引き継ぎ7日キット（MVP下書き）

状態: `preview_only / untested_with_other_households / unpublished`

版: `0.1-draft`  
更新日: 2026-08-23（JST）

このキットは、生後1〜3か月ごろに夜間対応メモを約3か月使った一家庭の経験をもとに、別の家庭でも試せる形へ整理した未検証MVPです。

主対象は、2人以上の養育者の間に夜間または朝の引き継ぎがある家庭です。2人が同時に育休中である必要はなく、片方が就労中でも、就寝前・早朝・休日などに情報を受け渡す場合を含みます。

目的は、赤ちゃんを寝かせることや授乳間隔を決めることではありません。**記録できた範囲で、誰がいつ何をしたか、次に何を確認するかを見つけやすくすること**です。

## ファイル

1. `01-seven-day-night-log.csv` — Day 1〜7の夜間記録。各日4行入りで、必要なら行を複製する
2. `02-seven-day-review.csv` — 翌朝3分レビューと7日目の見直し
3. `03-handoff-card.md` — 交代前に読む短い引き継ぎカード
4. `04-setup-privacy-checklist.md` — 入力方法、共有範囲、失敗時の代替を決める

## 最初の使い方

1. 引き継ぎに関わる人同士で`04-setup-privacy-checklist.md`を確認する。
2. `01-seven-day-night-log.csv`をUTF-8対応の表計算アプリで開き、編集用コピーを作る。
3. 1晩だけ試し、翌朝に`02-seven-day-review.csv`を3分で埋める。
4. 入力が負担なら項目を減らすか、紙・音声・既存の育児記録アプリへ替える。
5. 7日目に「継続・変更・中止」を決める。

## 必要環境と開き方

- CSV 2点: UTF-8 CSVを開ける表計算アプリ。スマートフォンでは表計算アプリへ読み込み、原本を複製してから入力する。
- Markdown 2点: UTF-8テキストを開けるメモ／テキスト編集アプリ。見出し記号や`- [ ]`がそのまま見えても内容は利用できる。必要部分を普段の共有メモへコピーする。
- 紙で使う場合: 各アプリの印刷機能を使うか、必要な項目だけ紙へ書き写す。専用のA4 PDFは含まれない。
- 特定の有料アプリは不要。アプリごとの表示、印刷、共有機能は各提供元の仕様による。

## 安全上の境界

- 記録を優先して赤ちゃんへの対応を遅らせない。
- このキットは診断、授乳量・授乳間隔の指示、受診判断を提供しない。
- いつもと違う様子や心配があるときは、医療機関や公的相談先を優先する。
- 睡眠環境と緊急時の案内は、記事無料部にある公的情報を確認する。
