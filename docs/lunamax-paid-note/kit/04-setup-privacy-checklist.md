# 3分セットアップ／共有・プライバシーチェック

「2晩」「7日」は、このキットを無理に続けないための編集上の運用ルールです。医学的・統計的に効果が確認された基準ではありません。

## 1. 入力手段を1つ選ぶ

- [ ] 既存の育児記録アプリ
- [ ] 共有メモ／表計算
- [ ] 紙とペン
- [ ] 音声入力（共有先・誤認識を確認した場合だけ）

## 2. 最小項目を決める

- [ ] 時刻
- [ ] 記録者
- [ ] 対応の種類
- [ ] 次の人が確認すること

必要でない項目は増やしません。授乳量や間隔は、このキットが決めるものではありません。

## 3. 共有範囲を確認する

- [ ] 閲覧できる人を確認した
- [ ] 編集できる人を確認した
- [ ] 通知が夜間の負担にならない設定にした
- [ ] 氏名、住所、医療情報など不要な個人情報を入れない
- [ ] 音声入力を使う場合、誤認識と保存先を確認した

## 4. 記録できなかったときのルール

- [ ] 推測で埋めず「記録なし」とする
- [ ] 記録より子どもへの対応を優先する
- [ ] 2晩続けて負担なら項目を減らすか入力手段を替える
- [ ] 7日目に継続・変更・中止を決める

## 5. 引き継ぎ

- [ ] 交代時に`03-handoff-card.md`の要点だけ確認する
- [ ] 心配な様子がある場合は記録より相談・受診を優先する
