# 有料note レイアウト／カバー制作ブリーフ

対象商品：**生後1〜3か月・2人以上の養育者向け「夜間対応の記録と引き継ぎ7日キット」**  
状態：価格・対象再評価を反映した制作設計／非公開  
作成日：2026-08-23

> この文書は、記事の見せ方と画像制作の指示書である。睡眠・授乳・受診に関する医療判断を提供するものではない。売上、睡眠時間、夜泣き減少、安全性向上などの成果は保証しない。

## 1. 結論

採用する見せ方は、**「赤ちゃんを眠らせるノウハウ」ではなく、「複数の養育者が夜間対応を記録し、次の人が前回対応を見つけやすくするための実用品」**である。

- 公開タイトル案：**生後1〜3か月 夜の引き継ぎ7日キット**
- 冒頭補足：**2人以上の養育者で、記録→共有→翌朝3分の見直し。両方の育休は不要**
- カバー主見出し：**夜の引き継ぎ 7日キット**
- 無料部で伝えるもの：対象者、困りごと、キットの中身、できること／できないこと、著者の一次経験の範囲、安全・相談先、1枚の縮小プレビュー
- 有料部で渡すもの：記入手順、7日分のテンプレート、引き継ぎカード、翌朝3分レビュー、記入例、CSV／Markdownファイル
- 有料ライン：**安全情報と商品適合性を無料で確認でき、完全版テンプレートを受け取る直前**

内部データは「需要の存在」と「競合タイトル上の空白」を示すが、購入確率や売上を証明しない。したがって、カバーや本文で「売れている」「必ず役立つ」「睡眠が改善する」とは表現しない。

## 5. 図表・テンプレートの画像仕様

### 5.1 共通仕様

- 元画像：**幅1,240px**を基本とし、note上で幅620pxへ縮小されても文字が潰れない2倍書き出しを想定する。
- 表示単位：スマホ1画面で「見出し＋1図＋2〜3文」に収まる程度を目安にする。
- レイアウト：横長表ではなく、**上から下へ読む1列カード**。
- 文字：本文相当の文字を画像内へ詰め込まない。1図につき見出し1つ、要素4〜6個まで。
- 色だけで状態を区別せず、アイコン・ラベル・線種を併用する。
- 各画像直後にテキスト要約を置く。ALTは1〜2文で、目的と主要な流れを書く。
- 個人名、出生日時、医療情報、実際の相談本文は画像へ入れない。

**根拠**：noteは幅620pxを超える本文画像を自動縮小し、ALT入力に対応する。公式の読みやすさ案内はスマホ、画像、見出し、短い段落を重視する。  
**推論**：2倍書き出しと1列カードは、縮小後の可読性と縦スクロールに適する。  
**限界**：1,240px、4〜6要素、1画面という数値は制作上の目安であり、note公式の成果保証や厳密なアクセシビリティ基準ではない。公開前に実機確認する。

### 5.2 画像ごとの指示

#### 図1：無料部「3ステップ」

`月のアイコン → 1行記録 → 交代矢印 → 翌朝3分レビュー`

- 説明語：**記録する／次の人へ渡す／朝に1つだけ調整**
- 禁止語：改善、解決、最適化、正常化
- ALT例：「夜間の対応を記録し、次の養育者へ引き継ぎ、翌朝に運用を3分で見直す3ステップ図。」

**根拠**：無料部で便益を具体化するnote公式分析と、Mamariの夜間×複数養育者の需要信号。  
**推論**：商品の処理単位を3つに絞ると、睡眠ノウハウではなく共同作業ツールだと伝わる。  
**限界**：この順序が購入率や家庭内摩擦を改善する実証はない。

#### 図2：無料部「縮小プレビュー」

- 1夜分の空欄テンプレートを70〜80%縮小し、3項目だけ架空入力する。
- 「記入例（架空）」を図内に常時表示する。
- 氏名、具体的な体重、投薬、診断、個別の授乳指示は入れない。

**根拠**：note公式分析は購入前に便益・内容を示す重要性を示唆し、noteは無料プレビュー範囲を設定できる。  
**推論**：完全版を隠し切るより、使用感を見せた方が購入前の適合判断がしやすい。  
**限界**：70〜80%という縮小率に効果検証はない。読めなさで価値を演出しない。

#### 図3：有料部「1回分の夜間対応」

縦順：`時刻 → 担当 → 行ったこと → 次の人へのメモ`

- 「行ったこと」はチェック＋自由記述。授乳、おむつ、抱っこ等は行為の記録に留める。
- 「次に○時間空ける」「この状態なら問題ない」等の指示は入れない。

**根拠**：対象商品の中心価値は記録と申し送り。安全・医療情報は公式一次情報を優先する。  
**推論**：時系列と担当を縦に並べると、スマホで横スクロールせず利用できる。  
**限界**：項目の有効性は一家庭の一次経験を基にした運用仮説で、臨床的な記録票ではない。

#### 図4：有料部「引き継ぎカード」

縦順：`最後にしたこと → 次に確認すること → 交代時刻 → 未解決メモ`

- 「緊急度」の自己判定スコアは設けない。
- カード外の無料安全欄へ「迷う場合は#8000、緊急時は119」を案内する。

**根拠**：こども家庭庁の公的相談導線と、noteの健康情報への慎重な扱い。  
**推論**：運用メモと医療判断を同じカードで混ぜない方が、ツールの責任範囲が明確になる。  
**限界**：相談の必要性をこのカードが判定することはできない。

#### 図5：有料部「翌朝3分レビュー」

縦順：`伝わったこと → 詰まったこと → 今夜1つ変えること → 担当`

- 評価対象は「引き継ぎの運用」。睡眠時間、覚醒回数、授乳量を成果KPIにしない。

**根拠**：内部データは夜間・夫婦／複数養育者の困りごとを示すが、睡眠改善効果は観測していない。  
**推論**：一度に1つの運用変更なら、原因を断定せず家庭内で試行しやすい。  
**限界**：「3分」「1つ」は著者の運用設計で、効果を比較した試験結果ではない。

#### 図6：有料部「7日マップ」

- Day 1〜7を横並びにせず、2列以下または縦1列で配置する。
- 各日の欄は同じ4項目に揃える。
- 「睡眠が良くなった日」ではなく「引き継ぎが詰まった／伝わった」を振り返る。

**根拠**：スマホ中心の読みやすさと、商品の7日キットという提供範囲。  
**推論**：同じ項目の反復で、運用上の変化だけを比較しやすい。  
**限界**：7日という期間の臨床的・統計的妥当性はなく、行動定着や成果を保証しない。

## 6. カバー画像ブリーフ

### 6.1 推奨案A：文字主役（第一候補）

**キャンバス**：1280×670px  
**主見出し**：夜の引き継ぎ 7日キット  
**上部ラベル**：生後1〜3か月／2人以上の養育者へ  
**下部補足**：記録・共有・翌朝3分  

構図：

```text
┌────────────────────────────┐
│  生後1〜3か月／2人以上の養育者へ                 │
│                                                    │
│       夜の引き継ぎ                                 │
│           7日キット                                │
│                                                    │

│            記録・共有・翌朝3分                     │

```

- 背景：深いネイビー〜インディゴの単色またはごく弱いグラデーション
- 強調：暖色の月、ミント色の矢印、白い文字
- 情報階層：主見出し > 対象月齢 > 3つの用途
- 主要文字・アイコンは中央80%内、外周96pxには置かない（内部制作ルール）
- 乳児写真、寝具のある寝床、医療モニター風UIは使用しない

**根拠**：note推奨サイズ1280×670px、タイトル・カバーが最初の接点であること、情報系記事では文字で補足できるという公式案内。  
**推論**：商品名と用途を小さなサムネイルでも識別しやすくし、安全でない睡眠写真の含意を避ける。  
**限界**：note公式が示す「見出し画像ありの記事はPV・スキが数十%高い」という投稿データは方法が非公開で、因果・購入率・育児カテゴリへの適用は不明。配色や抽象図のクリック効果も未検証。

### 6.2 比較案B：フロー主役

- 中央に大きく `記録 → 引き継ぎ → 翌朝3分`
- 左上に小さく「生後1〜3か月」、右下に「7日キット」
- 人物は性別を固定しない2つの抽象アイコン

**根拠**：商品の処理フローを視覚化し、タイトルで説明し切れない情報をカバーが補うという公式案内。  
**推論**：家族形態を「母／父」に限定せず、2人以上の養育者へ広く適合する。  
**限界**：案Aとの優劣を示す購入データはない。公開時は同時比較できないため、流入元・表示期間を揃えない単純比較は避ける。

### 6.3 カバーで使わない表現・描写

- 「7日で眠る」「夜泣き解決」「睡眠改善」「寝かしつけ成功」「夫婦喧嘩がなくなる」
- 「SIDS予防」「事故を防ぐ」「安全になる」「医師推奨」（根拠・許諾がない限り）
- うつ伏せ寝、枕・掛け布団・ぬいぐるみのある寝床、ソファや大人用ベッドでの添い寝
- 赤十字、聴診器、心拍波形、診断チャートなど医療サービスを連想させる意匠
- 赤ちゃんの泣き顔を大写しにした不安訴求、警告色の過剰使用
- 売上・販売部数・レビューを裏づけなしで示すバッジ

**根拠**：こども家庭庁の安全な睡眠環境の案内、note公式の誇張回避、内部DBに検証可能な売上データがほぼないこと。  
**推論**：商品の責任範囲を「共同養育の情報整理」に固定し、医療・恐怖・成果保証による誤認を防ぐ。  
**限界**：抽象表現だけで誤認が完全になくなるわけではない。タイトル、無料部、販売説明を一貫させる必要がある。

## 7. 医療・安全表現ガイド

### 7.1 使用可能な表現

- 「夜間対応の**記録と申し送りを助ける**ためのキットです」
- 「医療判断、受診判断、個別の授乳・服薬指示を置き換えるものではありません」
- 「心配な症状や対応に迷う場合は、かかりつけ医、助産師、保健師、#8000等へ相談してください」
- 「こども家庭庁は、1歳になるまでは医学上の理由で医師から別の指示がない限り、仰向けに寝かせることなどを案内しています」
- 「SIDSの原因は分かっておらず、予防方法は確立していません。公式情報ではリスクを低くするためのポイントが案内されています」

### 7.2 使用しない／要修正の表現

| 避ける表現 | 理由 | 修正例 |
|---|---|---|
| 睡眠が改善する | 効果を測定していない | 対応履歴を次の人が確認しやすくする |
| 夜泣きが減る | 因果根拠がない | 夜間対応の記録を一か所にまとめる |
| SIDSを予防する | 予防方法は確立していない | 公式の「リスクを低くするためのポイント」へ案内する |
| この授乳間隔なら安全／正常 | 月齢だけで個別判断できない | 授乳の個別指示は医師・助産師等へ確認する |
| 受診不要／様子見でよい | 診断・トリアージに当たる | 心配・迷いがある場合の公的相談先を示す |
| 産後うつを防ぐ／夫婦関係が改善する | 心身・関係性への効果根拠がない | 情報共有時の確認項目を揃える |

**根拠**：こども家庭庁のSIDS・安全な睡眠情報、公的相談窓口、note公式の健康・医療情報への注意。  
**推論**：断定を避け、観察可能な機能と相談導線に限定すれば、ツールの役割を誤認しにくい。  
**限界**：表現ガイドは医学監修や法務審査ではない。公開前に安全領域の専門確認が望ましい。

## 11. 最終的な制作判断

1. **商品軸**は睡眠成果ではなく、夜間の共同養育オペレーションに固定する。
2. **無料部**は共感だけで引っ張らず、適合性・実物・安全・限界まで開示する。
3. **有料部**は長文知識ではなく、すぐ使えるテンプレートと短い手順を先に渡す。
4. **画像**は赤ちゃんの睡眠写真ではなく、2人以上の情報受け渡しを示す抽象図にする。
5. **主張**は「記録しやすい／確認しやすい」という機能に限定し、睡眠・医療・家庭関係の改善を約束しない。
6. **根拠の限界**として、内部note100件は市場全体でも販売実績DBでもなく、Mamari語句件数も購買意図ではないことを記事制作チーム全員で共有する。
7. **対象条件**は同時育休ではなく実際の引き継ぎの有無で定義し、**初期価格**は未検証仮説として500円に置く。
