1. 画面の目的と導線

おすすめカテゴリの「育児アイテム」一覧です。正規URLは /items/、カード押下先は /items/:id/ です。おすすめハブの「アイテム」から遷移します。

公開条件

content collectionから published=true のアイテムだけを一覧へ出す。

3. 表示・検索・絞り込み・並び替え

機能仕様
表示items content collectionを公開フラグで絞り、data-order順に初期表示。PCは2列、SPは1列。
検索タイトルまたは説明文の小文字化部分一致。入力イベントごとに即時更新。
絞り込みカテゴリーと対象月齢。実データから選択肢を生成し、未指定月齢も選択可能。条件はAND。
並び替えおすすめ順＝data-order昇順。月齢が低い順／高い順＝数値比較。月齢未指定は最後。
空状態表示対象が0件なら「条件に一致するアイテムはありません。」を表示。フィルター解除で再びカード表示。
シート絞り込みと並び替えは同一の下部シート。ハンドルの下スワイプ、背景クリックで閉じる。

4. データのキャッシュ・保存法則

  • アイテムはAstroの items content collectionからビルド時に静的生成。公開フラグはビルド時に評価。
  • 検索・カテゴリー・月齢・並び順は画面内メモリのみで、URLやIndexedDBへ保存しない。
  • ページリロード時は、公開アイテムを再生成したHTMLから読み込み、条件は初期状態へ戻る。
  • 標準のブラウザーHTTPキャッシュ以外のアプリ固有TTL／キャッシュキーはない。
